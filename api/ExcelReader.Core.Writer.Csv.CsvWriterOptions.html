Encoding

The text encoding to write. When not null, output is transcoded from UTF-8 as it is written. Defaults to null, meaning UTF-8 is written directly.

Encoding

Remarks

Counterpart to Encoding: fields are always formatted as UTF-8 internally, so a non-UTF-8 target is transcoded on the way out.

NewLine

The byte sequence written after each record. Defaults to CarriageReturnLineFeed, which is what RFC 4180 specifies.

public CsvNewLine NewLine { get; init; }

Property Value

CsvNewLine

Remarks

Fields containing \r or \n are quoted either way, so the choice does not change how the file reads back.

Quote

The byte used to quote a field that contains the delimiter, itself, or a line break. Defaults to ".

Whether the encoding's byte-order mark is written before the first record. Defaults to false.

bool

Remarks

Counterpart to DetectEncodingFromByteOrderMark. Writing one is what lets Excel open a UTF-8 file as UTF-8 rather than as the system code page.
