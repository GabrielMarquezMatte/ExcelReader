ExcelReader.Core.Reader
Assembly
ExcelReader.Core.dll

Entry point for opening Excel and CSV workbooks. Open(string, ExcelReaderOptions?)/ Open(Stream, bool, ExcelReaderOptions?) and their async counterparts auto-detect XLSX/XLSB/XLS from the file's signature and return a format-agnostic IExcelWorkbook; the From*/FromXls*/FromXlsb*/FromCsv* methods open a specific, known format directly.

EncryptPackage(Stream, Stream, ExcelPassword)

Wraps a finished plaintext OOXML package (XLSX or XLSB) in a password-encrypted CFB container, using agile encryption (ECMA-376 4.4): AES-256-CBC, SHA-512, 100,000 spin iterations, with a dataIntegrity HMAC.

public static void EncryptPackage(Stream package, Stream destination, ExcelPassword password)

Parameters

package Stream

The plaintext package, positioned at its first byte. Must be readable and seekable — it is read twice. Not disposed by this method.

destination Stream

Where the encrypted container is written. Need not be seekable. Not disposed by this method.

password ExcelPassword

The password required to open the result.

Exceptions

ArgumentNullException

Any argument is null.

ArgumentException

package is unreadable, not seekable, empty, or does not begin with the PK\x03\x04 package signature; or password is empty.

FromXlsb(ReadOnlyMemory<byte>, ExcelReaderOptions?)

Opens an XLSB workbook directly from an in-memory buffer. Reads the ZIP central directory without a ZipArchive. Small parts (workbook, styles, shared strings) are decompressed whole; each sheet is decompressed as it is enumerated. Nothing waits on I/O, so without PrefetchDecompression enumeration never suspends, even under await foreach.

public static XlsbWorkbook FromXlsb(ReadOnlyMemory<byte> data, ExcelReaderOptions? options = null)

InferSchema(IExcelSheet, SchemaInferenceOptions?)

Guesses a column schema for sheet by sampling it from the first row.

public static IReadOnlyList<ExcelColumnSchema> InferSchema(IExcelSheet sheet, SchemaInferenceOptions? options = null)

Parameters

sheet IExcelSheet

The sheet to sample. A new enumerator is opened and disposed; no other read of the sheet is disturbed.

options SchemaInferenceOptions

Header row, sample size and text parsing; Default when null.

Returns

IReadOnlyList<ExcelColumnSchema>

One ExcelColumnSchema per column, in column order.

Remarks

This is a guess over a bounded sample, not a guarantee about the whole sheet — a column whose first SampleSize rows are all integers is reported as Int64Column even if row 10,000 holds text. Verify it fits before trusting it, and feed the result into Build<T>(Action<ExcelRowMapBuilder<T>>, ExcelParserOptions?) to build a real map.

Exceptions

ArgumentNullException

sheet is null.

ArgumentOutOfRangeException

HeaderRow is negative, or SampleSize is not positive.

ArgumentException

The sheet has fewer rows than HeaderRow.

InvalidOperationException

HeaderRow is positive and sheet is a table view (AsSheet()) of a table without a header row.
