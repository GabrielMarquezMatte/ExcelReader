Identifies the kind of value a Cell holds.

[SuppressMessage("Design", "CA1027:Mark enums with FlagsAttribute", Justification = "Not flags: the values match the native XL_CELL_* codes, and 5 belonged to the removed Formula.")]
public enum CellType

Fields

Boolean = 4

The cell holds a boolean value.

Date = 3

The cell holds a numeric value whose style indicates a date/time format.

Empty = 0

The cell has no value.

Error = 6

The cell holds an Excel error value (e.g. #DIV/0!).

ExcelString = 1

The cell holds text (a shared string, an inline string, or a formula's text result).

Number = 2

The cell holds a numeric value.

Remarks

A formula cell reports the type of its cached result, the same in every format.
