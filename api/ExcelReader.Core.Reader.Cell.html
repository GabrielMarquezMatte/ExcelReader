TryGetDateTime(bool, out DateTime)

Interprets the cell's numeric value as an Excel serial date, falling back to an ISO-8601 text date (yyyy-MM-dd, optionally followed by T or a space, a time, and up to seven fractional-second digits) when the value is not numeric. A trailing zone designator is not accepted.

public bool TryGetDateTime(bool isDate1904, out DateTime result)

Parameters

isDate1904 bool

Pass true for workbooks using the 1904 date system (e.g. when the reader's IsDate1904 is true) so the epoch offset is applied correctly. Ignored for a text date, which carries its own calendar.

result DateTime

The parsed date, when this method returns true.
