Class ExcelStyleAttribute

Namespace
ExcelReader.Core.Writer
Assembly
ExcelReader.Core.dll

Styles a property's data cells when ExcelRecordLayout writes it; the header cell is left alone. The style replaces any column or row style on those cells. Colors are 0xRRGGBB, -1 for unset.

[AttributeUsage(AttributeTargets.Property)]
public sealed class ExcelStyleAttribute : Attribute
