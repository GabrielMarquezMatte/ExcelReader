Class XlsSheetWriter

Namespace
ExcelReader.Core.Writer.Xls
Assembly
ExcelReader.Core.dll

Writes a single sheet of a BIFF8 (.xls) workbook, buffering cell records in memory until the workbook is finalized. Rows beyond the BIFF8 65,536-row cap spill into an auto-generated continuation sheet.
