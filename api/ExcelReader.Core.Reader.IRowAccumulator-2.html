Folds typed rows read by SheetParallel.AggregateAsync into a result. Each partition of the sheet gets its own instance.

public interface IRowAccumulator<TSelf, TModel> where TSelf : IRowAccumulator<TSelf, TModel> where TModel : allows ref struct

Type Parameters

TSelf

The implementing type.

TModel

The record type, produced by TryParse(Row, out TSelf) or by an ExcelParser<T>.

Remarks

Add(TModel) runs concurrently across instances on worker threads, and must mutate only the instance it is called on. For CSV, a partition that started at a misguessed row boundary, which takes a quote outside RFC 4180 rules or a quoted field longer than 64 KB, is read again into a new instance and the first one is discarded, so an instance may see rows that are later thrown away — including rows whose parse or Add(TModel) threw, and rows misparsed from the wrong start that appear nowhere in the sheet. A side effect outside the instance is not undone. XLSX and XLSB never re-read a partition.

Merge(TSelf) runs on a single thread, left to right in sheet order, folding each later partition into the accumulator of everything before it. It may receive an instance that saw no rows.
