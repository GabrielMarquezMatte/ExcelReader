WriteRecordsAsync<T>(XlsxSheetWriter, IEnumerable<T>, Action<XlsxRowWriter, T>, CancellationToken)

Writes one row per item in records to an XlsxSheetWriter using its synchronous fast path, calling writeRow for each to populate that row's cells. Behaviorally equivalent to the generic ISheetWriter<TRow> overload, but resolved in preference to it when the caller's static sheet type is XlsxSheetWriter — e.g. plain IEnumerable<T> sources, which are the overwhelming majority.

[SuppressMessage("Reliability", "CA1849:Call async methods when in an async method", Justification = "Deliberately using XlsxSheetWriter/XlsxRowWriter's synchronous fast path — see the <remarks> above.")]
public static ValueTask WriteRecordsAsync<T>(this XlsxSheetWriter sheet, IEnumerable<T> records, Action<XlsxRowWriter, T> writeRow, CancellationToken ct = default)

Remarks

Safe because XlsxSheetWriter/XlsxRowWriter row buffering only ever touches the destination stream on the rare buffer-threshold flush (EndBufferedRow, already synchronous), so this overload skips the per-row ValueTask/async-disposable machinery entirely.
