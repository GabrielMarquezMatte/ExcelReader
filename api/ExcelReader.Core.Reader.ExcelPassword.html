A workbook password. Deliberately a class rather than a record: a record's synthesized ToString would print the password, and this type is held by ExcelReaderOptions, which is a record — so one logger.LogDebug("{Options}", options) would leak it. ToString() below is what makes that safe.

Remarks

On wiping secrets, plainly: a password that reaches this type as a string cannot be wiped — .NET strings are immutable, movable by the GC, and possibly interned. This type does not pretend otherwise, and deliberately does not use SecureString, which is deprecated and only ever protected anything on Windows. What the library actually does is zero the UTF-16 buffer it allocates during key derivation and zero the derived key when the reader is disposed — that key, not the password, is what lives in memory for the reader's lifetime.
