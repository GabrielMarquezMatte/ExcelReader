ExcelReader.Core.Writer

Record writes that format and compress batches of rows on several threads and write them in order. Memory is bounded by DegreeOfParallelism batches of BatchRows rows.

Remarks

The source is enumerated by one flow at a time, never concurrently. A writeRow delegate runs on pool threads, several at once, so whatever it captures must be safe to use concurrently; the layouts from ExcelRecordLayout are. Rows may be written through the normal API before and after a call, but not while one is running. A call that throws, a cancelled one included, ends the sheet and its workbook. With shared strings on, string indexes depend on thread timing, so two runs give the same content in files that differ byte for byte.

Writes a header row from layout, then one row per record, in parallel batches.

public static ValueTask WriteRecordsParallelAsync<T>(this XlsbSheetWriter sheet, IAsyncEnumerable<T> records, ExcelRecordLayout<T> layout, ParallelWriteOptions? options = null, CancellationToken ct = default)

Parameters

sheet XlsbSheetWriter

The sheet to write rows to.

records IAsyncEnumerable<T>

The records to write, one row each, in enumeration order.

layout ExcelRecordLayout<T>

The columns to write, from ExcelRecordLayout.

options ParallelWriteOptions

Degree of parallelism and batch size. Defaults to Default.

ct CancellationToken

A token to cancel the operation between batches.

Returns

ValueTask

Type Parameters

T

The record type being written.

Exceptions

ArgumentNullException

sheet, records or layout is null.

ArgumentOutOfRangeException

options holds a negative degree or a batch size below 1.

ObjectDisposedException

The sheet has already been ended.

InvalidOperationException

A row is still active on the sheet.

ExcelLimitExceededException

The records do not fit in the sheet's 1,048,576 rows.

OperationCanceledException

ct was cancelled. Unlike a serial write cancelled between rows, this ends the sheet and its workbook.
