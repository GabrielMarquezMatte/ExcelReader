A time of day, counted in microseconds since midnight.

TimestampColumn = 6

A date and time, counted in microseconds since 1970-01-01T00:00:00Z.

Remarks

The underlying values are fixed: they are the XL_T_* constants of the native C ABI (see src/ExcelReader.Native/include/excelreader.h), which marshals this enum with a plain integer cast rather than a translation table. Renumbering a member is a silent ABI break.

A minor version can add values, so a switch over this enum should have a default branch. See versioning and compatibility.
