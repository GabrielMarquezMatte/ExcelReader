Class ExcelParser<T>

Namespace
ExcelReader.Core.Parser
Assembly
ExcelReader.Core.dll

Parses rows from an Excel or CSV sheet into instances of T. Create one with ExcelParser: FromAttributes<T>(ExcelParserOptions?) reflects over [ExcelColumn]/[ExcelRequired]/[ExcelConverter] attributes, Generated<T>(ExcelParserOptions?) uses the [ExcelSerializable] source-generated map, and Build<T>(Action<ExcelRowMapBuilder<T>>, ExcelParserOptions?) takes a map configured at runtime.

public sealed class ExcelParser<T> where T : allows ref struct

Type Parameters

T

The model type to bind each row to. May be a ref struct, including one with a ReadOnlySpan<byte> property. A struct T consumed via a direct foreach skips the per-row model allocation a class T requires.

CsvEnumerable<T>

An enumerable that yields one T per data row.

Remarks

Uses a specialized enumerable (dense field binding, single-pass projection), since CSV rows have no gaps or styles. Prefer this overload over Parse(IExcelSheet) for CSV: a sheet held as IExcelSheet goes through the generic path.
