Thrown when a bound column's cell is non-empty but fails to parse into the target property type and the parser is configured to throw on parse failures (rather than silently keep the property at its default). See ThrowOnParseFailure.

Remarks

A parse failure on an [ExcelRequired] column always surfaces as a missing-required-value error instead, regardless of ThrowOnParseFailure, since the column has no usable value either way.
