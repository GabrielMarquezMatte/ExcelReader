Namespace ExcelReader.Core.Writer.Csv

Classes

CsvRowWriter

Writes the fields of a single CSV row, quoting a field only when it contains the delimiter, quote character, carriage return, or line feed.

CsvSheetWriter

The single sheet of a CSV "workbook". Adapts the flat ExcelReader.Core.Writer.Csv.CsvWriter to the ISheetWriter<TRow> contract that record writing drives.

CsvWorkbookWriter

Writes a CSV file through the IWorkbookWriter<TSheet> contract. A CSV file holds exactly one sheet, so only a single AddSheet(string) call is supported.

CsvWriterOptions

Configures the dialect, encoding, and record terminator used when writing a CSV file.
