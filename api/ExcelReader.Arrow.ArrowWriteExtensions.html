WriteRecordBatch(XlsxWorkbookWriter, RecordBatch, ArrowWriteOptions?)

Writes batch to workbook as one XLSX sheet, in a single call: adds the sheet, writes the header row (unless WriteHeader is false) and every data row, then ends the sheet and the workbook.

public static void WriteRecordBatch(this XlsxWorkbookWriter workbook, RecordBatch batch, ArrowWriteOptions? options = null)

Parameters

workbook XlsxWorkbookWriter

A freshly created, not-yet-started workbook writer.

batch RecordBatch

The batch to write. Supported Arrow types: string, large string, string view, every integer width (signed and unsigned), half float, float, double, decimal128, decimal256, boolean, date32, date64, time32, time64, timestamp and null.

options ArrowWriteOptions

The sheet name and whether to write a header row; Default when null.

Exceptions

ArgumentNullException

workbook or batch is null.

NotSupportedException

A column's Arrow type is not one of the supported types.
