Remarks

A CSV file is a single sheet, so the owning CsvWorkbookWriter exposes exactly one sheet and rejects a second AddSheet(string) call. The workbook owns the ExcelReader.Core.Writer.Csv.CsvWriter; this sheet only borrows it.
