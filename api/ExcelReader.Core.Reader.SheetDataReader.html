Remarks

The column shape is fixed once, at construction time, from the header row (or from the first data row when HeaderRow is 0) — it never grows as later, wider rows come in. There is no schema pass, so GetFieldType(int), GetValue(int), and the typed getters all read the current row's own cell type; a consumer that builds a schema (e.g. DataTable.Load, which calls GetSchemaTable() before the first Read()) locks in the first data row's types for the whole load; the constructor reads that row ahead for this.

One SheetDataReader reads one sheet: NextResult() always returns false. To read every sheet, construct one per SheetAt(int).

Disposing this reader disposes the row enumerator it created, not the workbook the sheet came from — the caller still owns that.
