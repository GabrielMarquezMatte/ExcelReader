SniffDialect

Gets a value indicating whether the source's dialect is inferred from a sample of its leading bytes at open time, replacing Delimiter and Quote with what CsvSniffer reports. Defaults to false.

Remarks

Applied by the entry points that own the source — FromCsvFile(string, ExcelReaderOptions?) and the other Excel.FromCsv* factories, Open(string, ExcelFileFormat, ExcelReaderOptions?) with Csv, and the parallel CSV entry points — since the sample has to be read before the reader starts. An explicitly set Encoding is kept unless the source carries a byte-order mark naming a different one. Sniffing a stream reads a sample and restores the position, so it requires a seekable stream.
