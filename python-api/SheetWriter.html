Class SheetWriter

A streaming workbook writer. Use as a context manager; closing finalizes the workbook, and for a destination with write() hands it the finished bytes.

The required call order is start_sheet -> write_row per row -> end_sheet. Calling out of order raises ExcelReaderError, and the writer stays usable: fix the order and continue, or close to discard.

write_row

def write_row(values: Sequence[Any]) -> None

Writes one row, one cell per value, its type inferred from the value.

str is text, bool a boolean, int a 64-bit integer, float a number, datetime a timestamp (an aware one converted to UTC), date a date and time a time of day. None is a blank text cell; the tuple (None, ColumnType.X) is a blank cell typed as X.

Raises, before writing anything, TypeError for a value whose type has no mapping and OverflowError for an int outside the signed 64-bit range.

close

def close() -> None

Finalizes and releases the writer. Safe to call more than once.

For a destination with write(), the finished workbook is written to it in one call, even when sheets or rows were left open.
