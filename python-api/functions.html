encrypt_package

def encrypt_package(
    package: Union[str, os.PathLike, bytes, bytearray, memoryview, io.BytesIO],
    destination: Destination,
    password: str,
) -> None

Wraps a finished plaintext XLSX/XLSB package in an agile-encrypted (ECMA-376 4.4) CFB container, the inverse of passing password= to open_workbook.

package is a path to a complete file, or its bytes (bytes, bytearray, memoryview, or an io.BytesIO read whole). destination is a path, or a binary object with write() that receives the encrypted workbook in one call and is not closed. Encryption parameters are fixed at Excel's own defaults; there are no options.

open_workbook

def open_workbook(
    source: str | os.PathLike[str] | bytes | bytearray | memoryview | IO[bytes] | Source,
    format: str | None = None,
    *,
    options: OpenOptions | None = None,
    password: str | None = None,
) -> Workbook

Opens a workbook from a path, bytes in memory, a Source, or a readable stream.

source picks how the workbook is read:

  • a str or path-like: the file on disk.
  • bytes, bytearray, memoryview or io.BytesIO: a copy the native side takes immediately. A BytesIO is read whole, whatever its position.
  • a Source (size and read_at): fetched in blocks on demand, and every sheet can be read on its own thread. The library keeps a reference to it until the workbook and everything read from it are closed. read_at runs with the GIL held, so a local file is better opened by path.
  • any other object with readinto() or read(), such as an open file, a pipe or sys.stdin.buffer: read as a stream that cannot seek. A CSV is read as it arrives, and can be read again from the start (infer_schema(), then a read) until 16 MiB of it were read; an XLSX, XLSB or XLS is read whole before the workbook opens. The library never closes it.

format is one of auto/xls/xlsx/xlsb/csv; None infers it, from the extension for a path and from the content otherwise. The content tells XLS, XLSX and XLSB apart, and a stream that is none of them reads as CSV; a CSV in memory or behind a Source needs format="csv". options overrides reader limits and CSV dialect settings; see OpenOptions. password unlocks an encrypted OOXML workbook (.xlsx/.xlsb); omitting it for one raises PasswordRequiredError, and a wrong one raises PasswordIncorrectError.

open_writer

def open_writer(
    destination: Union[str, os.PathLike, IO[bytes]],
    format: str | None = None,
    *,
    options: WriteOptions | None = None,
) -> SheetWriter

Opens a streaming writer for destination: a path, truncating any existing file, or a binary object with write() such as io.BytesIO or an open file.

format is one of xlsx/xlsb/xls/csv. For a path, None infers it from the extension; an object with write() needs it. Such an object receives the whole workbook in one write() call when the writer closes, and is not closed itself.

write_workbook

def write_workbook(
    destination: Destination,
    data: Any,
    types: list[ColumnType] | None = None,
    *,
    format: str | None = None,
    options: WriteOptions | None = None,
) -> None

Writes data as a single sheet to destination: a path, or a binary object with write() such as io.BytesIO or an open file.

data is one of:

  • a TypedTable, what Sheet.parse() returns, so reading a sheet and writing it back out is a round-trip through the same buffers. types then gives each column's ColumnType and is required: a TypedTable carries raw buffers, and nothing about a raw buffer's element size alone distinguishes, say, I64 from TIME — both are 8-byte-per-row arrays.
  • a pyarrow.RecordBatch or pyarrow.Table, a pandas.DataFrame (its index is not written), or any other table exposing __arrow_c_stream__, such as a polars.DataFrame. Each column's type comes from its Arrow type, so types must be None. Requires pyarrow.

format is one of xlsx/xlsb/xls/csv. For a path, None infers it from the extension; an object with write() has no extension, so it needs format. The whole workbook is built in memory and handed to write() in one call, at the object's current position; the object is not closed.

The column names become the header row. options sets the sheet name and CSV dialect; see WriteOptions.
