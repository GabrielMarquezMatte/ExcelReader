Class Sheet

One sheet of a Workbook: the native workbook handle and an index.

Holds no resource of its own, so it is cheap to copy and may be handed to another thread; each read opens what it needs. After its workbook is destroyed, every read on it returns XL_INVALID_HANDLE.

for_each_row

template <typename F>
std::expected<void, Error> for_each_row(F &&f) const

Calls f once per row on the calling thread, without copying rows into a cursor.

Each RowView borrows the library's buffers for that one call; copy anything you keep. A cell carries text, a number, or both: CellView::text() and CellView::as_number() cover all three. Returning anything but XL_OK stops the walk and comes back as the error's code; use positive codes, since every library status is <= 0. An exception from f stops the walk and is reported as an error. Other calls on this workbook are allowed from inside f.

aggregate

template <Accumulator Acc>
std::expected<Acc, Error> aggregate(
    const Acc & seed = Acc{},
    int32_t header_row = 0,
    int32_t degree_of_parallelism = 0) const

Folds this sheet into one Acc across several threads.

Each chunk starts from a copy of seed, made on a worker thread; copies are made concurrently from the one seed, which the call only reads. The CSV dialect, password and limits come from the OpenOptions the workbook was opened with.

Type parameters

Name Description
Acc The accumulator; see Accumulator.

Parameters

Name Type Default Description
seed const Acc & Acc{} The state every chunk starts from.
header_row int32_t 0 1-based header row, not aggregated; 0 means none.
degree_of_parallelism int32_t 0 Worker threads; 0 uses every processor, 1 runs sequentially.

Returns std::expected<Acc, Error>: The combined accumulator.
