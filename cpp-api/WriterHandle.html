Class WriterHandle

Writes a workbook as calls arrive instead of building it in memory first.

Per sheet: start_sheet, then for each row start_row, one write per cell from left to right, and end_row; then end_sheet. A call out of order returns an error rather than corrupting the output. Closed on destruction.
