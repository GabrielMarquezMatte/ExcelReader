Class WriterHandle

Writes a workbook as calls arrive instead of building it in memory first.

Per sheet: start_sheet, then for each row start_row, one write per cell from left to right, and end_row; then end_sheet. Or one write_columns or write_sheet per whole sheet. A call out of order returns an error rather than corrupting the output. Finish with finish(); destruction finishes too, but cannot report a failure.
