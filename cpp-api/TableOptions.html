Struct TableOptions

Writes a sheet as an Excel table ("Format as Table"), through WriterHandle. XLSX/XLSB only.

struct xl::TableOptions

Fields

Name Type Default Description
name std::string_view Unique in the workbook, ignoring case, and valid as an Excel name. Borrowed: must outlive the write.
style std::optional<std::string_view> "TableStyleMedium2" A built-in table style, or empty for no style.
row_stripes bool true Band alternate rows.
column_stripes bool false Band alternate columns.
first_column bool false Emphasize the first column.
last_column bool false Emphasize the last column.
