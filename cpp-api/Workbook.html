Class Workbook

An open workbook, closed on destruction.

Safe to use from several threads at once: every read goes through a Sheet and opens its own cursor.

open_stream

static std::expected<Workbook, Error> open_stream(
    std::unique_ptr<InputStream> stream,
    int32_t format = XL_FORMAT_AUTO,
    const OpenOptions * options = nullptr)

Opens a workbook over a stream that cannot seek.

A CSV is read as it arrives, and again from the start until 16 MiB of it were read; an XLSX, XLSB or XLS is read whole first.

Parameters

Name Type Default Description
stream std::unique_ptr<InputStream> Owned by the library from here on.
format int32_t XL_FORMAT_AUTO As for Workbook::open.
options const OpenOptions * nullptr As for Workbook::open; max_buffered_bytes caps what an XLSX, XLSB or XLS may buffer.
