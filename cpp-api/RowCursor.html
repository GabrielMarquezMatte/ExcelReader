Class RowCursor

Reads one sheet row by row.

Owns a native cursor and closes it on destruction. Use one cursor from one thread at a time; any number may be open on one workbook.

next_row

std::expected<RowView, Error> next_row()

Reads the next row.

Returns std::expected<RowView, Error>: A view into memory the cursor owns, valid until the next next_row() or the cursor's destruction. The end of the sheet arrives as an error whose code is XL_EOF.
