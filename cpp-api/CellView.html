Struct CellView

One cell of a row, borrowing the row's memory.

struct xl::CellView

Fields

Name Type Default Description
column int32_t {} 0-based column.
type CellType {} What the cell holds.
value std::string_view {} The text as stored, so a date is its serial number. Empty for a cell that carries only a number.
number std::optional<double> {} The library's own double, set only by Sheet::for_each_row and Sheet::aggregate, and only when the cell carries one.

Methods

as_number

std::optional<double> as_number() const

number when set, else value parsed as a double.

Returns std::optional<double>

text

std::string text() const

value when non-empty, else number in shortest round-trip form, else empty.

That formatting is this header's own, so it can differ from the text xl_rows_next writes.

Returns std::string
