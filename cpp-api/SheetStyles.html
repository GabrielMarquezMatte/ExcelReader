Struct SheetStyles

Styles and widths for a whole-sheet typed write: WriterHandle::write_columns and write_sheet.

Column styles reach the data cells only, never the header row; a style without a number format keeps a date, time or timestamp column's format.

struct xl::SheetStyles

Fields

Name Type Default Description
column_styles std::vector<std::optional<CellStyle>> {} By column index; empty or missing entries leave a column unstyled.
column_widths std::vector<double> {} Characters, 0-255, by column index; 0 keeps the default.
header_style std::optional<CellStyle> {} The header row's style.
