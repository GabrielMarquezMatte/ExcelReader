Struct OpenOptions

Reader limits and CSV dialect for the Workbook::open family.

A field left at 0 or XL_OPT_DEFAULT keeps the library default; on/off fields take XL_OPT_TRUE or XL_OPT_FALSE. The max_* fields bound what a malformed or hostile file can make the reader allocate: lower them for untrusted input. An out-of-range value fails the open with XL_INVALID_ARGUMENT.

Methods

password

OpenOptions & password(std::string_view value)

Sets the password that unlocks an encrypted OOXML workbook (.xlsx/.xlsb/.xlsm).

Open the workbook with XL_FORMAT_AUTO: XL_FORMAT_XLSX reads the encrypted container as a plain ZIP and fails before the password is checked.
