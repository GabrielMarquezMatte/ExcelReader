aggregate_csv

template <CsvAccumulator Acc>
std::expected<Acc, Error> aggregate_csv(
    std::string_view path,
    const Acc & seed = Acc{},
    const OpenOptions & options = {},
    int32_t header_row = 0,
    int32_t degree_of_parallelism = 0)
template <CsvAccumulator Acc>
std::expected<Acc, Error> aggregate_csv(
    std::span<const uint8_t> data,
    const Acc & seed = Acc{},
    const OpenOptions & options = {},
    int32_t header_row = 0,
    int32_t degree_of_parallelism = 0)

Folds the CSV file at path into one Acc across several threads.

Each partition starts from a copy of seed, made on a worker thread; a partition that has to be re-read starts again from a fresh copy, so a copy can be destroyed without ever being combined. Copies are made concurrently from the one seed, which the call only reads.

Folds an in-memory CSV buffer into one Acc; otherwise as for the path overload.

Type parameters

Name Description
Acc The accumulator; see CsvAccumulator.

Parameters

Name Type Default Description
path std::string_view CSV file to read.
seed const Acc & Acc{} The state every partition starts from.
options const OpenOptions & {} csv_delimiter, csv_quote, csv_detect_bom and max_cell_bytes apply; the other fields are ignored.
header_row int32_t 0 1-based header row, not aggregated; 0 means none.
degree_of_parallelism int32_t 0 Worker threads; 0 uses every processor, 1 runs sequentially.
data std::span<const uint8_t> The CSV bytes. Not copied, so they must stay valid for the call.

Returns std::expected<Acc, Error>: The combined accumulator.
