Struct CsvParallelOptions

Settings for aggregate_csv_file and aggregate_csv_memory.

A zero field keeps the library default.

struct xl::CsvParallelOptions

Fields

Name Type Default Description
degree_of_parallelism int32_t 0 Worker threads; 0 uses every processor, 1 runs sequentially.
header_row int32_t 0 1-based header row, not aggregated; 0 means none.
delimiter int32_t 0 Field separator byte. Default ,.
quote int32_t 0 Quote byte. Default ".
detect_bom int32_t XL_OPT_DEFAULT Skip a leading UTF-8 byte-order mark. On by default.
max_cell_bytes int32_t 0 Largest field or buffered record. Default 32 MiB.
